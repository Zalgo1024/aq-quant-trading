## 2. 总体架构

```
数据源(akshare/tushare/mock) → 数据层(清洗/复权/存储)
   → 因子层(计算/中性化/验证) → 模型层(截面+时序+LLM)
   → 组合层(打分/风控/仓位) → 执行层{SimGateway | 实盘Adapter}
   → API(FastAPI) → 前端(React+ECharts)
因子/模型/组合 → MLOps(监控/版本/再训练)
```

**核心原则**：策略/组合/风控只依赖抽象接口；回测、模拟、实盘**共用同一事件循环与撮合内核**，切换仅由配置决定。

## 4. 接口契约

### 4.1 MarketFeed（行情源）

```python
class MarketFeed(ABC):
    def history(symbol, start, end, freq="1d") -> list[Bar]
    def get_bar(symbol, dt, freq="1d") -> Bar | None
    def subscribe(symbols, freq="1d") -> None          # 实时源
    def on_bar(cb: Callable[[Bar], None]) -> None      # 逐 bar 回调
```

实现：`MockFeed`（合成，确定性）、`HistoricalFeed`（provider 包装）、`ReplayFeed`（历史回放）。

### 4.2 TradingGateway（交易网关 —— 模拟/实盘分水岭）

```python
class TradingGateway(ABC):
    name: str
    def connect(cfg: Settings) -> None
    def disconnect() -> None
    def get_account() -> Account          # 返回快照副本
    def get_positions() -> list[Position]
    def submit_order(order: Order) -> Order
    def cancel_order(oid: str) -> bool
    def get_order_status(oid: str) -> Fill | None
    def on_fill(cb) -> None               # 成交回报（实盘异步推送）
```

**实现类**：`SimGateway`（可用）｜`QMTAdapter` / `PTradeAdapter` / `JoinQuantAdapter`（预留壳，调用即抛 `NotImplementedAdapter`）。

**契约保证**：所有下单失败以 `Fill(status=REJECTED/UNFILLED, reason=...)` 返回，**不抛异常**。

### 4.3 RiskEngine（风控 —— 模拟与实盘共用）

```python
class RiskEngine:
    def pre_trade_check(order, account, bar) -> tuple[bool, str]
    def portfolio_check(orders, account, bars) -> tuple[list[Order], list[(Order, str)]]
    def check_stop_loss(account) -> list[tuple[str, str]]
```

校验项：黑名单(ST/退市)、停牌、涨跌停、流动性门槛、T+1/不可裸卖空、单票上限、现金、总仓位、行业上限、止损。

### 4.4 Portfolio（组合构建）

```python
class Portfolio(ABC):
    def construct(predictions, account, prices, ts) -> list[Order]
```

实现：`TopKPortfolio`（评分 TopK 等权调仓）、`EqualWeightPortfolio`。

## 5. 核心数据类型

```python
Order   = {oid, symbol, side:BUY|SELL, qty(100倍数), type:LIMIT|MARKET,
           limit_price, status, strategy_id, account_id, created_at, reason}
Fill    = {oid, symbol, side, filled_qty, avg_price, commission, stamp_tax,
           transfer_fee, slippage_cost, status, reason, ts}
Account = {account_id, cash, frozen, positions:dict, realized_pnl, updated_at}
          + market_value / total_asset / unrealized_pnl（属性）
Position= {symbol, qty, available(T+1), avg_cost, last_price, realized_pnl}
Bar     = {symbol, time, freq, ohlcv, amount, pre_close, limit_up, limit_down, is_trading}
Prediction = {symbol, score, confidence, direction, factor_contrib[], model_version, explain}
```

## 7. A 股规则与 SimGateway 撮合

### 7.1 规则常量（`aq/core/rules.py`）

| 项 | 值 |
|---|---|
| 佣金 | 万 2.5，**最低 5 元** |
| 印花税 | 千 0.5，**仅卖出** |
| 过户费 | 万 0.1 |
| 滑点 | 千 1（默认） |
| 涨跌停 | 主板 ±10%｜科创/创业板 ±20%｜北交所 ±30%｜ST ±5% |
| 交易单位 | 100 股/手；T+1；不可裸卖空 |

### 7.2 撮合伪码

```python
def execute(order, next_bar, account, risk_engine):
    # 1) 事前风控（与实盘共用）
    ok, reason = risk_engine.pre_trade_check(order, account, next_bar)
    if not ok: return REJECTED(reason)

    # 2) 停牌
    if not next_bar.is_trading: return UNFILLED("停牌")

    # 3) 涨跌停封板
    if BUY  and next_bar.open >= next_bar.limit_up - eps:   return UNFILLED("涨停封板")
    if SELL and next_bar.open <= next_bar.limit_down + eps: return UNFILLED("跌停封板")

    # 4) 限价单未触及
    if LIMIT and BUY  and order.limit_price < next_bar.open: return UNFILLED(...)
    if LIMIT and SELL and order.limit_price > next_bar.open: return UNFILLED(...)

    # 5) 成交价 = 下一根 bar 开盘价 ± 滑点
    fill_px = next_bar.open * (1 + slippage * (+1 if BUY else -1))

    # 6) 资金/持仓校验（不足则缩量或拒单）
    ...

    # 7) 更新账户
    if BUY:
        cash -= turnover + fees
        pos.qty += qty
        pos.available 不变             # T+1：当日买入不可卖
    else:
        cash += turnover - fees        # 含印花税
        pos.qty -= qty; pos.available -= qty
        realized_pnl += (fill_px - avg_cost) * qty

    persist(account)                  # 落 JSON，重启不丢
    return FILLED / PARTIAL
```

**杜绝未来函数**：订单在 t 日收盘后生成，用 **t+1 日 bar** 撮合。

## 8. 配置示例

`config/base.yaml`（节选）：

```yaml
mode: paper                    # backtest | paper | live
data:
  source: mock                 # mock | akshare | tushare
  adjust: post                 # 后复权
backtest:
  start: "2018-01-01"
  end: "2026-06-30"
  initial_cash: 1000000.0
  benchmark: "000300"
  cost: { commission: 0.00025, min_commission: 5.0, stamp_tax: 0.0005, slippage: 0.001 }
risk:
  single_stock_max: 0.10
  industry_max: 0.30
  total_position_max: 0.95
  stop_loss: 0.08
model: { cross_section: lightgbm, top_k: 20, score_threshold: 0.55 }
frontend: { theme: dark, up_color: red, currency: CNY }
execution: { broker: sim, persist_path: runtime/sim_account.json }
```

**环境变量覆盖**：`AQ_MODEL__TOP_K=7`、`AQ_EXECUTION__BROKER=qmt`（双下划线表示层级）。
**切实盘**：改 `mode: live` + `broker: qmt` + 填账号，策略代码零改动。

### 9.3 视觉规范

### 9.4 可解释性（差异化重点）

把"冷热号/遗漏/分布"换成真实因子（动量/反转/量比/换手突变…），
展示每个因子对最终评分的**贡献值与权重**，红=偏多、绿=偏空，回答"为什么推荐"。
