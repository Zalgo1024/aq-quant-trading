# 退市股数据层与数据源裁决（阶段 1b）

> 2026-09-18 定案。这是「无偏数据底座」的第二块：**已退市 A 股的历史日线**。
> 没有它，任何在现役池上做的研究都带幸存者偏差（`probe_survivorship.py`：
> 2018 年后退市 259 只、年均 ~32 只、占池 0.7%~1.2%/年；bp Top20 年拖累粗估 1.3~4.4pp）。

## 1. 退市清单（`data_cache/delisted_list.parquet`）

- 来源：`stock_info_sh_delist`（159 行）+ `stock_info_sz_delist`（208 行）。
- 列名坑：两接口的日期列分别叫「**暂停上市日期**」（沪）与「**终止上市日期**」（深）——
  都不含字面「退市」二字。且**沪市只给暂停上市日**（真终止日更晚），实际采用列
  记录在 `date_col_note`，引用时注意口径。
- 构成：沪 153 唯一代码（159 行含 6 个重复）∪ 深 208 = 361，剔 B 股 28 → **333 只 A 股**。
- 与现役池交集 = 0 ✓（脚本内置自检）。
- 按退市年份（近 12 年）：2022/23/24/25/26 = 43/45/52/29/19 —— 与股票侧探针的
  46/46/55 同量级（口径差异来自清单 vs 面板）。

## 2. ⭐ 数据源裁决（三源实测，别再翻）

判据：与主池（新浪 hfq）的**日收益率**一致性——重叠日 |Δr| 中位 < 1e-4 且
99 分位 < 5e-3（真口径一致时实测 ~1e-6/~1e-5；真口径错单日 ≥1e-2）。

| 源 | 结果 | 证据 |
|---|---|---|
| **baostock（采用）** | ✅ 中位 1.24e-06 / q99 1.07e-05（000002，2112 重叠日） | 事实锚：2024-09-27 万科 +9.95% vs 公开涨停 ≈+10% ✓；5 只现役股 crosscheck 全 OK（最大中位 3.30e-05、最大 q99 1.59e-04，`runtime/delist_crosscheck.log`） |
| 腾讯 `stock_zh_a_hist_tx` | ❌ **否决** | 万科 2024-09 涨停潮单日 hfq 收益 +4.5~4.9% vs 真实 +10%（比例系数 ~0.5）；与主池 corr 仅 0.959；价格比年化漂移 +12.7%。另坑：其 `adjust=""` 参数不生效，永远返回 hfq |
| 东财 `stock_zh_a_hist` | ❌ 不达标 | 与主池中位差 1e-3~3e-3；且被代理间歇拦截（同日一次通一次拦） |
| 新浪 `stock_zh_a_daily` | ❌ 不可用 | 对退市代码全部 JSONDecodeError |

**方法论**：三个源互不一致时，用**公开事实（涨停价）当锚**。新浪与 baostock
两条独立链互相印证一致（1e-6 量级），腾讯单方面错。2024-09-27 万科涨停 +10%
一个数字同时完成「验证对源」与「否决错源」。

## 3. 落盘口径（`data_cache/delisted_bars/`）

- 文件名 = **裸 6 位代码**（与主池 `bars/` 一致）；交易所前缀在清单 `exchange` 列。
- hfq 构造：`adj_factor = close_hfq / close_raw`（同日比，两趟查询：
  `adjustflag="3"` 不复权 + `adjustflag="1"` 后复权），满足主池恒等式
  「后复权价 = 真实价 × adj_factor」→ **收益层面可与主池混用**（经 crosscheck 验证）。
- 停牌行（`tradestatus≠1`）整行丢弃，与主池（新浪无停牌行）对齐。
- volume 单位 = 股（baostock 与新浪一致，无需换算）。
- 抓取窗口 `--start 2005-01-01`（研究起点）；2005 前退市的 25 只在窗口内无
  交易日 → 无文件，属预期。

## 4. 验收（2026-09-18，`runtime/_verify_delisted.py`）

- **306/333 落盘**；2005 前退市 25 只（窗口外，空 = 预期）；**真缺口仅 2 只**：
  `600788 *ST达曼`（退市 2005-03-25）、`000765 *ST华信`（退市 2005-07-04）——
  退市前长期停牌的僵尸股，合计占清单 0.6%，影响可忽略。
- 已落盘 × 退市年份：2005-2026 每年都有（2022-2026 = 43/45/52/29/19）。
- `adj_factor` 异常文件 **0**；末行比退市日晚 45 天以上的 **0**。

## 5. 已知边界（如实记录）

1. 沪市清单只有暂停上市日 → 沪市退市股的「真实终止日」晚于清单日期，
   按 `delist_date` 做面板剔除会**晚剔除**（多留几个月僵尸数据）；深市无此问题。
2. 缺 2005-01-01 之前的退市股历史（研究窗口外，不影响 2005 起的面板）。
3. baostock 单连接非线程安全 → 脚本默认串行；并行要**多进程分片**
   （`--offset/--limit`），单进程内多线程会串数据。
4. 退市股的**分红送转明细**未拉（B3 红利路线需要时另起：baostock
   `query_dividend_data` 或 `stock_fhps_em` 对退市代码的覆盖待验证）。

## 6. 方法论教训

1. **「能拉到数据」≠「数据是对的」**：腾讯源 6/6 拉取成功、行数正常，
   但收益率是错的（涨停日只剩一半）。任何新源入库前必须过
   收益一致性 crosscheck + 公开事实锚。
2. crosscheck 的容差要按**噪声上界**设定（本轮：tx 价格 2 位小数 → 舍入
   噪声 ~1e-4~2.5e-3；真口径错 ≥1e-2 → 判据取 5e-3）。1e-6 这种「看起来严格」
   的判据会 100% 误报，等于没有判据。
3. 同一文件的多个编辑**必须串行**（并行 Edit 读-改-写互相覆盖，
   「成功」提示是真的，改动会被兄弟调用抹掉——本轮实踩，333 只全挂）。
