### 2. 关键约定：后复权价 vs 真实价（**本项目最容易踩的坑**）

| 用途 | 用什么价 | 原因 |
|---|---|---|
| 因子计算、收益率、信号 | **后复权** `bar.close` | 除权日收益率连续，不会出现假跳空 |
| 撮合成交价、资金、股数、手续费 | **真实价** `bar.open_raw` / `bar.close_raw` | 后复权价可能是真实价的十几倍（浦发 2026 年后复权 159.66、真实 9.18） |
| 涨跌停判断 | **真实价尺度**算出再换算回复权尺度 | 交易所按真实价四舍五入到分；直接在后复权价上乘 1.1 会差 0.60 元，足以把涨停误判成没涨停 |

### 3.1 修复：复权因子每日抖动（170 只股票，最多 1058 次跳变）

**现象**：质检报 170 只股票「复权因子跳变疑似噪声」。

**根因**：新浪的**后复权价与真实价都只保留 2 位小数**。"分"这个最小单位对
3 元股就是 0.33% 的量化误差 —— 而真实除权跳变与噪声的分界线本就在 1% 量级：

```
t          close_hfq  close_raw   adj
2019-06-21   5.40       5.24    1.030534
2019-06-24   5.35       5.20    1.028846   ← 只差 0.16%，不可能是除权
```

**解法**（`aq/data/adj.py` + `scripts/fix_adj_factor.py`）：变点检测（>1% 才算真除权）
+ 段内取中位数（噪声对称，中位数是最优估计）。同步修正 `limit_up`/`limit_down`
（真实价尺度上本就正确，只需按新因子换算回复权尺度）。

**效果**：全市场跳变 **83,612 → 20,523（-75.5%）**；极端案例 601588 从 1058 次 → 5 次；
误判的涨停记录从 123,975 降到 77,230；质检异常清零。

> 已知残余误差：后复权价本身的 2 位小数取整仍给 `close_raw` 带来约 ±0.2%（低价股）
> 的噪声。它是零均值随机误差，在数千笔成交上会抵消，量级也小于滑点模型（千一）。
> 彻底消除需直接存不复权 OHLC（改 `Bar` 模型 + 重拉），列为待办。

### 关键设计决策（与初始计划的偏差及理由）

1. **不接 alphalens，自己实现 `ic.py`**
   - alphalens-reloaded 依赖老版 pandas API，与本项目 pandas 2.x + pyarrow 环境冲突；
   - 它按"美股日历 + 无涨跌停"设计，不处理 A 股一字板不可交易问题；
   - 自研版用 **Newey-West 修正 t 值**（持有期重叠会让 IC 序列自相关，
     普通 t 检验系统性高估显著性）——这点 alphalens 也没做。

2. **不引入财务/资金流/北向因子（本轮）**
   - 这些是**低频 + 有前视风险**的数据：财报有公告滞后，龙虎榜/北向是 T+1 才公开；
   - 本轮先把**纯量价**这条最干净的路走通，P2.5 再补估值（用新浪快照按复权价
     折算回历史的方法，见下）。

3. **因子计算只有一套实现**
   - `vlib.py` 是唯一算法来源，`library.py` 只做"Bar 列表 → DataFrame → 取最后一行"
     的适配。避免"回测有效的因子，实盘算出来是另一个值"这类最隐蔽的 bug。

4. **`rev_20` 被删除**：它与 `mom_20` 横截面相关系数 = **-1.000**（数学上恒等于
   `-mom_20`）。同时放进因子池会让 IC 加权把同一条信息算两遍。1 月反转效应由
   `mom_20` 承担（实测 IC 为负 → 方向自动翻转为 -1，等价反转因子）。

- **组合优化**：风险平价 / 均值-方差 / Black-Litterman
- **MLOps**：Prefect 调度 + MLflow 版本 + 因子 IC 漂移监控
- **RL 执行**：强化学习优化下单拆单
