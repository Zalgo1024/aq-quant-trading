## 0. 为什么需要"换收益来源"而不是"再调参数"

现有框架（IC 加权多因子 + 月度/双周调仓 + 行业与换手上限）已经被自己的统计工具证伪：

| 检验 | 结果 | 读法 |
|---|---|---|
| 量价+IC 加权（`liquid_v2`） | PBO 0.121、best_t 0.128、6/6 alpha 全负 | 挑参可复现，但因为根本没有 alpha 可挑 |
| 分年度 | 4 赚 4 亏（2019 +21%、2020 −18%、2022 −27%、2024 +36%） | 严重 regime 依赖，不是稳定信号 |
| 估值单因子（`liquid_neu_val`，修好口径后） | 最优 t=0.477、alpha −0.001、**超额口径 t=−0.778** | 正收益来自 beta，非 alpha |
| 规模因子 | ln_mktcap t=−1.43 | A 股 2019-2026 小市值效应不显著 |

**关键判据**：继续在"持有期 / 成交额门槛 / 因子子集"上扫参数，只会把噪声拟合得更好 ——
因为 CSCV 已经告诉我们，**挑出来的最优配置在样本外不成立**。所以 B 不是"调参阶段"，
而是"回答收益从哪里来"的阶段。

**唯一还没被用掉的内生线索**：成本。下节把它量化出来。

## 1. 判据先行：每个候选必须自带零假设基准

这是本项目踩过最深的一个坑（见 README「研究结论 · 两个读数陷阱」与
A 阶段 TVD 判据的返工）：**任何"从大池子里挑少数"的指标，必须先建随机基准**，
否则读到的是抽样噪声。

所以本阶段每个候选在开跑**之前**必须先写下对照：

| 候选 | 必须有的零假设/对照 | 通过标准 |
|---|---|---|
| B1 成本感知定权 | 现状 `|RankICIR|` 定权，同口径同调仓 | 扣除成本后的净 IR 显著改善（t 检验），且不是换手下降带来的 beta 漂移 |
| B2 指数增强口径 | 等权持有基准指数；随机 K 只 | 相对基准的年化超额 IR > 0 且 t 显著 |
| B3 红利/低波 | **直接买对应 ETF** | 只有显著跑赢"直接买 ETF"才成立（否则不如买 ETF） |
| B4 ETF 轮动 | 等权买入所有候选 ETF（买入持有） | 同上 |
| B5 网格 | 买入持有 + 同波动率随机择时 | 同上 |

⚠️ **共同陷阱**：所有候选都要用同一套 CSCV / DSR 框架验收，且 PBO 的零假设基准
随候选集上移（ρ̄≈0.98、N_eff≈1.0 时 PBO 天然偏低），不能把"PBO 低"当成好消息。

## 2. 第一层 B1：把「换手」提升为定权的一等公民（**先做这个**）

### 2.1 问题：现在的权重恰好压在换手最高的因子上

`scoring.py` 按 `|RankICIR|` 定权，**完全不看换手**。实测（`full_neu_v2`，23 个因子有权重）：

| 因子 | 组合权重 | 单因子换手 | 权重×换手 |
|---|---|---|---|
| vol_ratio | 0.0973 | 0.5108 | 0.0497 |
| turnover_chg | 0.0788 | 0.2128 | 0.0168 |
| up_down_vol_20 | 0.0725 | 0.2569 | 0.0186 |
| turn_rate_20 | 0.0609 | 0.0411 | 0.0025 |
| **gap** | 0.0565 | **0.7945** | 0.0449 |
| hl_range_20 | 0.0545 | 0.0658 | 0.0036 |
| rsi_14 | 0.0527 | 0.2617 | 0.0138 |
| mom_20 | 0.0509 | 0.2099 | 0.0107 |
| ma_bias_60 | 0.0481 | 0.1486 | 0.0071 |
| **intraday_ret** | 0.0470 | **0.8313** | 0.0390 |
| rev_5 | 0.0447 | 0.3877 | 0.0173 |
| skew_20 | 0.0444 | 0.1813 | 0.0080 |

- **组合加权平均换手 = 0.2641**
- **估值三因子（bp/ep/sp）合计权重 = 4.54%** —— 而它们自己的换手只有 **0.0148~0.0205**
  （是量价因子的 1/30 ~ 1/50）

也就是说：**信号强度最高的因子恰好是最贵的因子，最便宜的因子几乎没被分配权重。**
这与"交易成本吃掉 alpha"这个瓶颈正面冲突。

### 2.2 反事实推算：把 |RankICIR| 换成 |RankICIR| / 换手

保持其余管线**逐字不变**（同一套 select 结果、组内 min-max、单因子 cap 0.25、幂次 1.0），
只把定权指标换成净口径：

| 口径 | 加权平均换手 | 估值三因子权重 |
|---|---|---|
| 现状 `|RankICIR|` | 0.2641 | 4.54% |
| **`|RankICIR| / 换手`** | **0.0731（−72.3%）** | **36.92%（×8.1）** |

权重最大的因子从 `vol_ratio / turnover_chg / gap`（换手 0.51 / 0.21 / 0.79）
换到 `sp / turn_rate_20 / bp / ep / vol_60`（换手 0.015 / 0.041 / 0.021 / 0.019 / 0.040）。

> ⚠️ **这是权重空间的推算，不是回测结果。** 实际实现的换手还会被调仓频率
> （h5d/h10d/h20d）与风控上限约束，降幅不会正好是 72%。

### 2.3 诚实标注：这个假设的先验并不高

必须说清楚 B1 的天花板和风险：

1. **估值因子本身已经被测出没有 alpha**（t=0.477、超额口径 t=−0.778）。
   B1 提高它们的权重，是在"更便宜但更弱"和"更强但更贵"之间换位置 ——
   **净效应未知**，这正是它值得测一次的原因。
2. `turnover` 是**样本内**估计量。用它定权本身是一个新的自由度，
   有可能把一种过拟合换成另一种过拟合 → 必须走 walk-forward 版（`ic_wf`）验收，
   而不是用全样本权重回测。
3. 这是**唯一一个不需要新数据、不需要新代码模块的内生杠杆**，成本极低。
   它的价值不只是"可能有效"，更在于**给现有框架一个了断**：
   如果连换手降 72% 的组合都跑不出显著超额，那这个框架就该封存。

### 2.4 实现路径（最小改动）

- `ModelConfig` 增 `ic_cost_penalty: float = 0.0`（0 = 现状，1 = 完全按净 IC）。
  定权值改为 `|RankICIR| / turnover**ic_cost_penalty`；`turnover` 从 `summary.csv` 的
  `turnover` 列读（已有，无需新数据）。
- 保留 `--factor-set` 与 `--score-neutralize` 两个维度在缓存 key 里的做法，
  `ic_cost_penalty` 也**必须进缓存 key**（同一类坑，已在本项目踩过两次）。
- 验收：`--weights ic,ic_wf` 两版 × penalty ∈ {0, 0.5, 1.0}，
  只报 **CSCV 之后的 PBO / DSR / 超额 t**，不看单次回测净值。

## 3. 第二层 B2：把评价口径从"绝对收益"改成"相对超额"

### 3.1 理由：我们一直在用错的尺子

估值路线修好口径后，最优配置 **alpha = −0.001、beta = 0.71**。
这解释了为什么"从 −0.99% 变成 +3.52%"看起来像改善 —— 那全靠 beta。
再看 CSCV 里的两个口径：

| 口径 | 年化夏普 | t | DSR |
|---|---|---|---|
| 绝对收益 | +0.172 | +0.477 | 0.205 |
| **超额（策略 − 基准）** | **−0.287** | **−0.778** | 0.019 |

**同一组交易，换把尺子就从"微微正"变成"负"**。既然我们要的是 alpha，
那目标函数就应该是**相对基准的 IR 与跟踪误差**，而不是绝对夏普。

### 3.2 具体形态

- 基准：`000300`（已有基准数据）；可选 `000905`（中证 500，需补数据）。
- 约束：跟踪误差上限（如年化 6%）、行业偏离上限、个股权重上限。
- 目标：最大化 IR = 超额收益 / 跟踪误差。
- 复用：`aq/backtest/engine.py` 已算 alpha/beta/IR，`--excess` 路径已有；
  主要改动是**把 IR 提到验收指标的位置**，并加跟踪误差约束。

**成本**：零新数据。**风险**：估值因子 |IC| 只有量价的 1/3~1/4，超额可能太薄。

## 4. 第三层 B3/B4/B5：换真正的收益来源（需要新数据）

这一层才是字面意义的"换收益来源"。三个候选按**与现有代码栈的复用度**排：

### B3 红利 / 低波 / 质量（复用度中）
- **逻辑**：A 股 2019-2026 红利风格有明显 regime（2021-2024 显著强于成长）。
  低波异象在 A 股也被反复报告，且**天然低换手** —— 与 B1 的成本逻辑兼容。
- **新数据**：股息率、分红记录、ROE/现金流等基本面（akshare 可取；
  现有 `runtime` 里只有行情 + 估值三因子）。
- **零假设**：**直接买中证红利 ETF**。跑不赢就别做。
- **风险**：本质上可能退化成"静态持有红利" = 不如直接买 ETF。

### B4 ETF 轮动（复用度中低）
- **逻辑**：完全不同的收益来源（行业/宽基 ETF 之间的动量与资金流），
  与个股 alpha 无关。标的少（几十个）、**无印花税**、容量大、成本结构更友好。
- **新数据**：ETF 日线 + 份额/规模（akshare 可取）。
- **零假设**：等权买入全部候选 ETF 并持有。
- **风险**：需要一套新的标的池与拥挤度判断；现有因子面板是**个股**口径，不能直接搬。

### B5 网格 / 均值回复（复用度最低）
- **逻辑**：A 股散户结构下均值回复确实存在，且与截面因子是正交的机制。
- **新数据**：需要更高频（分钟级）或至少更细的波动率/流动性状态划分。
- **零假设**：买入持有 + 同波动率的随机择时。
- **风险**：容量小、对滑点极敏感；本项目已有的日频数据可能不够。

## 5. 明确不做（附理由）

| 不做 | 理由 |
|---|---|
| 因子择时 / regime 条件化定权 | 只有 2019-2026 共 8 年、分年度 4 赚 4 亏 → 条件化必然过拟合 |
| 继续扫持有期 / 成交额门槛 / 因子子集 | CSCV 已证明挑出来的最优配置样本外不成立；只是把噪声拟合得更好 |
| 做小市值的暴露 | ln_mktcap t=−1.43，效应不显著 |
| 继续加因子（31 → 更多） | 问题不在因子数量，在收益来源与成本 |
| 靠提高换手率找 alpha | 方向与已确认的"成本是瓶颈"相反 |

## 6. 执行顺序与决策规则

```
B1（成本感知定权，零新数据）
   ├─ 显著改善 → 采信，回到"指数增强口径"(B2) 上重复验收
   └─ 不改善   → 现有框架封存（结论：IC 加权多因子在 A 股这段样本上无可用 alpha）
                     ↓
B2（超额口径重估，零新数据）—— 无论 B1 结果如何都要做，因为它修正的是"尺子"
                     ↓
B3 / B4 二选一（需补数据）
   ├─ B3 若跑不赢"直接买红利 ETF" → 放弃
   └─ B4 若跑不赢"等权持有 ETF"   → 放弃
                     ↓
B5 仅在 B3/B4 都不成立、且愿意引入更高频数据时启动
```

**每一步的验收只认 CSCV 之后的 PBO / DSR / 超额 t**，不认单次回测净值曲线 ——
这是本项目从 `liquid_v2` 到 `liquid_neu_val` 反复验证过的教训。
